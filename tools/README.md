# tools/ — генераторы игрового контента

Скрипты на Python, которыми собраны колоды в `server/game/data/`. Нужны, чтобы
расширять и пересобирать контент пачками, а не править JSON руками.

| Файл | Что генерирует |
|---|---|
| `gen_a.py` | `phobias.json`, `luggage.json` |
| `gen_b.py` | `backpack.json`, `facts.json`, `specials.json` |
| `gen_c.py` | `catastrophes.json`, `bunker.json`, `help.json` |

Колоды персонажа `professions`, `biology`, `body`, `traits`, `health`, `hobbies`
написаны напрямую в JSON.

## Запуск

```bash
python tools/gen_a.py     # перезапишет свои файлы в server/game/data/
npm test                 # tests/decks.test.js проверит структуру и объёмы
```

Скрипты **перезаписывают** файлы целиком, поэтому после запуска обязательно
прогоняйте `npm test`: тесты проверяют обязательные поля, уникальность `id` и
`title`, длину текстов и подсказок, допустимые значения `effect`/`targeting`
у спец. возможностей и `kind` у карт бункера.

## Правила контента

- `id` уникален **во всём наборе**, а не только внутри файла.
- `title` не повторяется нигде — на этом построена проверка утечек в
  `tests/e2e/check-privacy.js`.
- `tip` обязателен: это подсказка по аргументации для новичка, а не пересказ `text`.
- Тон — мрачноватый, с чёрным юмором, без пошлости и реальных имён.
